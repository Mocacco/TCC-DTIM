# RESUMO

---

Este trabalho consiste no desenvolvimento de um algoritmo de inteligência artificial baseado em aprendizado de máquina para detecção de tumores cerebrais em imagens médicas, como radiografias, ressonâncias magnéticas e tomografias computadorizadas. O objetivo é processar automaticamente essas imagens, identificando regiões suspeitas com precisão e auxiliando no diagnóstico médico. Como resultado final, espera-se obter um modelo funcional, eficiente e validado, capaz de auxiliar profissionais da saúde na detecção precoce de tumores, contribuindo para um diagnóstico mais ágil e preciso.

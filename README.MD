# RESUMO

Este trabalho consiste no desenvolvimento de um algoritmo de inteligência artificial baseado em aprendizado de máquina para detecção de tumores cerebrais em imagens médicas, como radiografias, ressonâncias magnéticas e tomografias computadorizadas. O objetivo é processar automaticamente essas imagens, identificando regiões suspeitas com precisão e auxiliando no diagnóstico médico. Como resultado final, espera-se obter um modelo funcional, eficiente e validado, capaz de auxiliar profissionais da saúde na detecção precoce de tumores, contribuindo para um diagnóstico mais ágil e preciso. 

---

# Objetivos

Objetivo Geral:
Desenvolver um sistema computacional baseado em aprendizado de máquina para a detecção automática de regiões suspeitas de tumores cerebrais em imagens médicas, servindo como uma ferramenta de auxílio ao diagnóstico para profissionais da área da saúde.
Objetivos Específicos:
- **1**Construir um banco de dados consolidado a partir da coleta de imagens médicas de fontes públicas, contendo casos positivos e negativos para tumores.
- **2** Aplicar técnicas de pré-processamento nas imagens para normalizar e otimizar os dados para o treinamento do modelo.
- **3** Desenvolver, treinar e validar um modelo de inteligência artificial, utilizando arquiteturas de redes neurais convolucionais (CNNs), para a classificação e/ou localização de tumores.
- **4** Avaliar a performance do modelo treinado utilizando métricas de desempenho consagradas, como acurácia, precisão, sensibilidade (recall) e F1-Score.
- **5** Criar uma interface de usuário simples e funcional que permita o upload de uma imagem médica e exiba o resultado da análise do modelo.
